# frontend

MS-TMDB 前端项目（Vue 3 + TypeScript + Vite + TailwindCSS）。

> 前端技术栈、目录分层与编码细则见仓库根目录 [AGENTS.md](../AGENTS.md)（AI 编码必读，改代码前先读）。

## 开发

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
pnpm preview
```

## 类型检查

```bash
pnpm typecheck
```

## 目录

- `src/pages`：页面
- `src/router`：路由
- `src/api`：API 请求封装
- `src/style.css`：Tailwind 入口与全局样式
